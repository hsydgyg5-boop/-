تقرير فحص محلي — مشروع مزاجي للاستضافة
التاريخ: 2026-10-29

التغييرات في هذه النسخة:
1. إضافة إجراء استعادة للنسخة الاحتياطية الكاملة من لوحة الإدارة، بجانب تنزيل النسخة الحالية.
2. تسمية ملف التنزيل بالعربية: قاعدة_بيانات_مزاجي_الكاملة.zip.
3. استعادة db.json ومجلدات USERS وphp_files والنسخ الاحتياطية الموجودة داخل DATA_DIR من ZIP واحد.
4. التحقق من ملف البيان وصيغة قاعدة البيانات، وحدود حجم الأرشيف وعدد الملفات، ومنع مسارات ZIP الخارجة والملفات المكررة والمتعارضة والروابط الرمزية.
5. إنشاء نقطة رجوع تلقائية قبل الاستبدال، وإرجاع البيانات السابقة تلقائيًا إذا فشلت عملية الالتزام.
6. إعادة ضبط مسارات المشاريع إلى مسار التخزين في الاستضافة الجديدة، مع ضبط حالة المشاريع إلى متوقفة وإزالة PID والمنفذ القديم.
7. إبقاء أسماء المسارات التقنية مثل db.json وUSERS كما يحتاج التطبيق داخليًا، مع عرض التسميات للمستخدم بالعربية.

اختبارات محلية نجحت:
- py_compile لملفات Python الرئيسية.
- node --check لكل كتل JavaScript المضمّنة في admin_panel.html وindex.html وlogin.html.
- اختبار وظيفي على ملف ZIP تجريبي: إنشاء النسخة مع البيان وملفات مشروع المستخدم.
- اختبار استعادة: استبدال حالة بيانات تجريبية، ثم التأكد من رجوع المستخدم والملفات وتغيير مسار المشروع إلى مسار الاستضافة الحالية.
- التأكد أن المشاريع المستعادة تظهر بحالة Stopped ولا تحمل PID أو منفذًا قديمًا.
- التأكد من إنشاء backups/pre_restore_latest.zip كنقطة رجوع.
- رفض أرشيف يحاول استخدام ../ للهروب من مجلد الاستعادة، مع التحقق من عدم تغيير البيانات الحالية.
- فحص رفض المسارات المطلقة ومسارات Windows ذات محرك القرص.

حدود الفحص:
- تعذر تثبيت Flask لأن بيئة الفحص لا تملك اتصالًا بمستودع الحزم؛ لذلك اختُبرت دوال المسار والنسخ والاستعادة محليًا عبر Flask shim بدل خادم HTTP حقيقي. نجاح الاختبار الوظيفي لا يساوي اختبارًا كاملًا على Flask الحقيقي أو Railway.
- لم يُنشر المشروع إلى حساب Railway ولم تُختبر صلاحيات الـ Volume الفعلية أو قيود الذاكرة والمساحة على الاستضافة.
- الحد الحالي لحجم ملف ZIP المرفوع هو 500 MB والحد الإجمالي بعد فك الضغط 2 GB. يجب أن تتوفر مساحة إضافية مؤقتة أثناء الاستعادة.
- ملف النسخة الكاملة حساس وقد يحتوي بيانات المستخدمين ومفاتيح API وملفات المشاريع. احتفظ به بمكان خاص.
